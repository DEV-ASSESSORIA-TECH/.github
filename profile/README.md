# ASSESSORIA TECH 🚀

### Soluções para empresas em, suporte técnicos especializado, desenvolvimento de sistemas Web, automação e gestão Pública

A **ASSESSORIA TECH** atua no desenvolvimento de soluções tecnológicas voltadas para automação de processos, sistemas web, integrações e apoio à gestão pública e empresarial.

Nosso foco é criar ferramentas úteis, organizadas e eficientes para resolver problemas reais do dia a dia.

---

## 💼 Áreas de atuação

- Sistemas ERP

- Soluções Microsoft
- Integrações com APIs públicas
- Automação de processos
- Infraestrutura web
- Backups automatizados

---

## 📊 Projetos principais

### ERP Empresarial

Sistema voltado para organização de processos internos, controle administrativo, relatórios e expansão modular de funcionalidades.

### Gestão de Licitações com Integração PNCP

Plataforma para acompanhamento e organização de licitações públicas, integrada ao **PNCP — Portal Nacional de Contratações Públicas**.

### Gerador de Diários de Obra

Ferramenta para automatização da geração de diários de obra, reduzindo trabalho manual e padronizando registros.

### Backup Automatizado via SFTP

Sistema de backup com foco em segurança, organização e confiabilidade no envio de arquivos.

### Gateway Web com Nginx

Infraestrutura web utilizando **Nginx** como reverse proxy para múltiplos serviços, domínios e aplicações.

### Automação DNS-01 para SSL/TLS

Automação do desafio **DNS-01** para emissão e renovação automática de certificados SSL/TLS.
